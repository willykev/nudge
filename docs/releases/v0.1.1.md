A security and bug-fix release, from a full code and security review of 0.1.0.

### Security

- Reminder text is always shown as plain text: tags, link labels, list names,
  and messages from an import or another program can no longer load remote
  images or restyle the window.
- The command line shows control characters in reminder text harmlessly, so
  an imported reminder cannot write to the clipboard or rewrite the terminal.
- Builds no longer run qmake files left above the source tree, such as one
  another user puts in `/tmp`.
- A link that is not a web link shows its scheme, so it never looks like one.

### Highlights

- Typing in the details pane always lands on the reminder it was typed for,
  and a title being typed is kept when the keyboard moves elsewhere.
- Undo keeps adding and naming a reminder as one step, and changes from other
  programs no longer clear the undo history.
- Quick entry reads "tonight at 9" as 21:00, and "5:30" the way "5" is read
  on a 12-hour clock.
- Alert buttons act only on the moment they announced, and a background alert
  opens a visible window.
- The command line follows the window's rules for times, dates, repeats, and
  tags, and reports a write that fails.

See [CHANGELOG.md](https://github.com/willykev/nudge/blob/v0.1.1/CHANGELOG.md)
for every change.

### Install

Download the `nudge-reminders-0.1.1-1-aarch64.pkg.tar.*` package below for an
ARM64 Arch/Omarchy system and install it with `sudo pacman -U <package-file>`.
The package is unsigned; `SHA256SUMS` records the release file checksums.

For Intel/AMD (`x86_64`), build from source on Arch/Omarchy:

```sh
git clone --branch v0.1.1 https://github.com/willykev/nudge.git
cd nudge
bin/install
```

The attached `PKGBUILD` also builds from the versioned source archive and
checks its SHA-256 hash. Run `makepkg -si` in a folder containing that recipe.
See the README for build dependencies.

### Upgrading

Your reminders carry over. If background reminders are on, restart them after
upgrading so the new version sends them: `systemctl --user restart nudge`.
