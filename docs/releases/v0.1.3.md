A new README, with pictures drawn by Nudge itself. Reminders, alerts and
keys work as they did in 0.1.2.

- **README:** pictures of Nudge at work (a list with its details, a
  reminder being typed as Nudge reads its date, the Scheduled view, the
  calendar, one list in four themes), a short tour, measured performance,
  and how to update and remove Nudge.
- **Pictures of the window:** `nudge open --screenshot` takes a window size
  (`--size`), an Omarchy theme (`--theme`), a time to take it to be
  (`--now`), and words for a new reminder to start with (`--type`).
- **For contributors:** `bin/screenshots` redraws the README's pictures
  from `examples/week.json`, off screen.
- **Guide:** how to update and remove Nudge, and what to check when an
  alert does not arrive.

See `CHANGELOG.md` for the full list.

### Install

Download the `nudge-reminders-0.1.3-1-aarch64.pkg.tar.*` package below for an
ARM64 Arch/Omarchy system and install it with
`sudo pacman -U nudge-reminders-0.1.3-1-aarch64.pkg.tar.*`. The package is
unsigned; `SHA256SUMS` records the release file checksums.

For Intel/AMD (`x86_64`), build from source on Arch/Omarchy:

```sh
git clone --branch v0.1.3 https://github.com/willykev/nudge.git
cd nudge
bin/install
```

The attached `PKGBUILD` also builds from the versioned source archive and
checks its SHA-256 hash. Run `makepkg -si` in a folder containing that recipe.

### Upgrading

Your reminders carry over. If background reminders are on, restart them after
upgrading so the new version sends them: `systemctl --user restart nudge`.
