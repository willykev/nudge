First public release of Nudge for Omarchy.

Keep reminders organized with lists, subtasks, due dates, repeats, tags,
and priorities. Includes desktop notifications, an optional background service,
keyboard shortcuts, JSON backups, and a command-line interface.

### Install

Download the `nudge-reminders-0.1.0-1-aarch64.pkg.tar.*` package below for an ARM64
Arch/Omarchy system and install it with `sudo pacman -U <package-file>`.
The package is unsigned; `SHA256SUMS` records the release file checksums.

For Intel/AMD (`x86_64`), build from source on Arch/Omarchy:

```sh
git clone --branch v0.1.0 https://github.com/willykev/nudge.git
cd nudge
bin/install
```

The attached `PKGBUILD` also builds from the versioned source archive and
checks its SHA-256 hash. Run `makepkg -si` in a folder containing that recipe.
See the README for build dependencies.

### Scope

Reminders stay on this machine. Device sync is not included. Background
alerts must be enabled with `nudge background on`.
